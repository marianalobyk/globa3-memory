Item Memory — Globa 3 Creative Radar

Brief ID

globa3_creative_radar

Display Name

Creative Radar

Memory File Use Rule

This Item Memory file is an internal production file only.

It tracks recurring, high-risk, or previously seen talent, project, IP, festival, creator, athlete-media, artist-to-IP, relationship, newsletter, source-risk, repetition, and story-world signals that require repeat-control.

It must guide:

* repeat detection
* daily vs rolling-context control
* source-to-claim control
* Globa 3 relevance control
* celebrity / gossip rejection
* weak-source control
* external-safe vs internal-only analysis
* relationship-action discipline
* source-log leakage prevention
* repeated-item compression
* festival overstatement prevention
* daily-brevity discipline
* final export discipline

It must not be pasted into the reader-facing draft or final Creative Radar.

Only memory updates from BLOCK B of 08_FINALIZE_AND_UPDATE_MEMORY_PROMPT.md should be added here, and only if they are useful for future repeat-control, source-risk, relationship, external-use, rolling-context, item-selection, or clean-output handling.

This Item Memory does not define the full coverage universe.

New talent, projects, artists, creators, athletes, institutions, festivals, labs, platforms, funds, or IP not listed here may still become elevated items if they meet all rules:

* fresh within the daily coverage window, or correctly labeled as rolling / forward-watch context;
* source URL is real and accessible;
* publication / announcement date is visible;
* source supports the claim;
* relevant to Gulf, Africa, or diaspora markets;
* strategically relevant to Globa 3 Studios, Advisory, Ventures, AMV, AFC, Unseen Arabia, Newsletter, or Relationship Map;
* not generic celebrity news;
* not gossip;
* not based only on unverifiable social media claims;
* not repeated across multiple sections without distinct operational value;
* not presented as externally safe if the analysis is internal-only;
* not included in reader-facing output with full source logs or internal artifacts.

Do not reject an item only because it is not listed in Item Memory.

If a new item is accepted or appears likely to recur, add it to Item Memory after the run.

festival_awards_overstatement

Topic: Inflated festival / award language.

Status: Source-to-claim and tone risk.

Fresh trigger required: Depends on item.

Known issue: Festival award items can be factually true but framed too strongly.

Avoid unless directly source-supported:

* swept;
* dominated;
* landmark;
* breakout;
* historic;
* unprecedented;
* major moment;
* first-ever;
* definitive;
* proved;
* took over;
* exploded;
* transformed;
* game-changing.

Prefer:

* won multiple awards;
* received festival validation;
* converted selection into awards;
* won across several categories;
* strong festival validation;
* notable awards showing;
* significant regional validation;
* one of the strongest regional signals this week.

Example risk:

Do not write:

Three African films swept Tribeca 2026.

unless the source explicitly frames it as a sweep.

Prefer:

Three African films won major Tribeca prizes in 2026.

or:

African films converted Tribeca selection into multiple awards.

Default final status impact:

* unsupported inflated festival language = blocks PASS — SAFE TO SEND;
* unsupported “first-ever” / “historic” / “landmark” claim = REJECT — DO NOT SEND if central;
* softened, source-controlled award claim = allowed.

institutional_incentive_live_status_qspi_2026_06_24

Topic: QSPI / institutional incentive live-status claims, Media City Qatar Film Committee, rebates, funds, grants, labs, markets, applications.

Status: Source-risk / institutional-status control.

Fresh trigger required: Yes for daily elevation. Current operational status requires official current source.

Known issue:
The Creative Radar output on 2026-06-24 stated that the Qatar Screen Production Incentive rebate was “now live” and “confirmed live in Q2 2026.” This overreached the available source language. Trade and launch coverage may confirm announcement context or expected timing, but it must not be rewritten as current operational status unless an official current source confirms application status, guidelines, or application mechanics.

Do not repeat as Lead unless:

* there is a fresh official announcement inside the daily window;
* or an official current application page / guidelines page / programme page confirms current operational status;
* or a verified deadline, application window, launch, or institutional update falls inside the forward-watch window.

Allowed placement without new trigger:

* Institutional / Festival / Funding Signals as forward watch, if an upcoming official deadline or application window is confirmed;
* Relationship Targets as “Verify / Map relationship” only;
* Advisory / Studios / Ventures context if clearly labeled internal only;
* Rejected / Not Elevated if current status cannot be verified.

Forbidden:

* “rebate is now live” without official current source;
* “confirmed live in Q2 2026” based only on “expected from Q2” language;
* “open,” “active,” “accepting applications,” “operational,” or “available” unless an official current source confirms it;
* treating trade launch coverage as proof of current application mechanics;
* marking institutional mechanics as Safe for external newsletter while eligibility or application status requires verification.

Default handling:

Use:
“QSPI was announced with applications expected from Q2 2026; current application status and mechanics require direct verification with Media City Qatar / Film Committee before external use.”

If an official current application page has been checked, use:
“Official Media City Qatar application materials indicate an application path is available; eligibility, qualifying-spend rules, and operational mechanics still require direct review before external use.”

Default final status impact:

* unsupported live / open / active incentive claim = REJECT — DO NOT SEND if central and uncorrected;
* useful but unverified institutional tracking item = PASS — INTERNAL ONLY — REFRESH REQUIRED;
* official current source checked but mechanics still need review = PASS — INTERNAL ONLY or PASS — INTERNAL ONLY — REFRESH REQUIRED;
* fully source-controlled external-safe fact only = may be Safe for external newsletter, but Globa 3 interpretation remains Internal only.

repeated_item_overuse

Topic: Same item appears across too many reader-facing sections.

Status: Daily brevity / repeat-control risk.

Fresh trigger required: Not applicable.

Known issue: Creative Radar can become a weekly dossier when a few strong items are repeated across Executive Summary, Talent Radar, Projects, Institutional, Artist-to-IP, Top 5, Relationship Targets, Projects to Watch, and Newsletter Themes.

Default allowed placements for one item:

1. one primary analytical section;
2. one operational section;
3. one weekly / theme / relationship section.

If the same item appears in more than 3 reader-facing sections, internal Repeat Justification is required.

The justification must explain:

* why each placement is necessary;
* what distinct operational function each placement serves;
* why compression would reduce usefulness.

Do not print Repeat Justification in the reader-facing brief.

Forbidden:

* same item repeated across 4+ sections with no new purpose;
* repeated items making the brief feel like a weekly memo;
* repeated project description copied with minor wording changes;
* one project dominating the brief because it is the easiest item to explain.

Default final status impact:

* repeated item across 4+ sections without justification = PASS — INTERNAL ONLY maximum;
* repeated item sprawl making brief unreadable = REJECT — DO NOT SEND;
* repeated item with distinct operational use and internal justification = allowed.

Status: Freshness and product-scope risk.

Known issue: Valuable older items may be included because they remain strategically important, but they must not overtake the daily product.

* old festival selection written as fresh;

* outside-window item dominating Executive Summary without forward relevance;
* rolling-context item repeated across many sections without decision value.

* rolling context dominates more than half the brief = PASS — INTERNAL ONLY maximum;
* outside-window item unlabeled = PASS — INTERNAL ONLY maximum or reject if misleading;
* outside-window item with forward deadline and clear label = allowed.

Topic: Possible action overreaches the source confidence.

Use Request screener only when:

* project is completed or screened publicly; or

* action does not imply Globa 3 already has access.

Use Map relationship when:

* person / entity is relevant but access path is unknown;
* item is useful for internal relationship intelligence;
* outreach would be premature.

Use Verify when:

* source quality is weak;
* rights / attachment / contact / screener / project status is unclear;
* signal is promising but not yet actionable.

Forbidden:

* Contact based only on weak source;
* Request screener for project with no evidence of completion, screening, festival, sales, or distribution path;
* Explore partner angle where partner relationship is speculative;
* action language implying Globa 3 already has access, rights, or relationship.

Default final status impact:

* action overreaches source confidence = PASS — INTERNAL ONLY maximum until fixed;
* outreach / screener / rights action based on weak or unsourced claim = REJECT — DO NOT SEND if presented externally;
* action downgraded to Watch / Map relationship / Verify = allowed.
