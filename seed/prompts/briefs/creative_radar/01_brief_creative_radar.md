Brief Objective

Create a daily Creative Radar that identifies emerging talent, projects, artists, filmmakers, athletes, creators, story worlds, and IP from the Gulf, Africa, and relevant diaspora markets that Globa 3 should know about before they become obvious.

The brief runs daily, while selected sections use a rolling 7-day context window to preserve continuity across the week.

This briefing is the human and creative layer that complements the existing Globa 3 intelligence system.

It should detect:

* who is emerging;
* what project matters;
* what story world is forming;
* what talent or creator Globa 3 should track;
* what regional project has received international validation;
* what could become a Studios, Advisory, Ventures, AMV, AFC, Unseen Arabia, or newsletter opportunity;
* what is too early for action but should enter the relationship map.

This is not a celebrity news roundup.

This is not generic entertainment news.

This is not a streaming guide.

This is not a box-office or review roundup.

This is not a maximal culture newsletter.

This is not a weekly scouting memo.

This is a source-controlled daily creative intelligence brief.

Repeat Compression Rule

Festival Awards Overstatement Rule

Festival validation is valuable, but awards language must be proportionate.

Do not use:

* swept
* dominated
* landmark
* breakout
* historic
* unprecedented
* major moment
* first-ever
* definitive
* proved
* converted the festival
* took over
* exploded

unless the source directly supports the scale of that claim.

Prefer:

* won multiple awards
* received festival validation
* converted selection into awards
* won across several categories
* strong festival validation
* notable awards showing
* significant regional validation

Example:

Do not write:

Three African films swept Tribeca 2026.

unless the source explicitly frames it as a sweep.

Prefer:

Three African films won major Tribeca prizes in 2026.

or:

African films converted Tribeca selection into multiple awards.

Unsupported festival overstatement blocks PASS — SAFE TO SEND.

If the factual award claims are source-controlled but the framing is too inflated, soften the wording.

Relationship Action Escalation Rule

Possible actions must match evidence confidence.

Allowed action labels:

* Watch
* Contact
* Map relationship
* Request screener
* Add to talent database
* Include in weekly themes
* Explore partner angle
* Verify
* No action yet

Use Contact only when:

* the item is source-controlled;
* the person / entity is clearly identifiable;
* the opportunity is strong enough to justify outreach;
* the relationship path is not invented;
* the action is proportionate to the signal.

Use Request screener only when:

* the project exists as a completed or screened work; or
* it has public festival / market / sales path suggesting a screener may plausibly exist;
* the project party is identifiable;
* the action does not imply Globa 3 already has access.

Use Map relationship when:

* the person or institution is relevant but no direct access path is known;
* the item is useful for internal relationship intelligence;
* outreach would be premature.

Use Verify when:

* source quality is weak;
* rights / attachment / contact / screener / project status is unclear;
* the signal is promising but not yet actionable.

Forbidden:

* Contact based only on weak source or vague relevance;
* Request screener for a project with no evidence of completion, screening, festival, sales, or distribution path;
* Explore partner angle where the partner relationship is speculative;
* action language implying Globa 3 already has access, rights, or relationship.

If an action overreaches source confidence, downgrade it.

Rolling 7-day section, updated daily.

PASS — SAFE TO SEND Threshold

Use PASS — SAFE TO SEND only when:

* all Executive Summary items are source-controlled;
* all source-quality labels are accurate;
* no Needs Verification item is presented as settled fact;
* every item has a clear Gulf / Africa / diaspora or Globa 3 connection;
* every external-use item is supported by Official / Primary or Strong Trade source;
* no gossip, social-only, or weak-source claim appears as fact;
* no review-only item is presented as strategic signal;
* no old item is presented as fresh;
* all possible actions are realistic and proportionate;
* External-use status is exactly one allowed value for every item;
* external-safe facts and internal-only analysis are separated where needed;
* no speculative relationship, rights, screener, contact, or access claim appears as externally safe;
* no full Sources section or source log appears in the reader-facing output;
* no duplicate header / export artifact appears near the end;
* repeated items have been compressed or justified internally;
* festival award language is proportionate and source-supported;
* Source support is present in the Evidence Index or separate internal source notes and supports the exact claims;
* Source-to-Claim QA was completed.

Use PASS — INTERNAL ONLY when:

* the brief is useful for internal scouting;
* one or more items need verification before external use;
* relationship, rights, screener, contact, or source confidence requires caution;
* some items are source-controlled enough to track but not safe for newsletter language;
* creative interpretation is useful but not externally source-safe;
* rolling context is useful but too dominant for external daily send;
* repeated items require internal compression before external circulation.

Use PASS — INTERNAL ONLY — REFRESH REQUIRED when:

* the brief is useful internally;
* a high-value item requires same-day source refresh before external use;
* an application deadline, festival update, grant window, platform announcement, or relationship-sensitive item may have changed;
* source status is close to safe but needs one more check before external circulation.

Use REJECT — DO NOT SEND when:

* any major item is unsupported;
* gossip or weak-source material is presented as fact;
* a Needs Verification item is written as externally safe;
* old items are presented as new;
* source support is missing from the Evidence Index or separate internal source notes;
* Final Approval Status would be misleading;
* the brief is padded with low-value entertainment content;
* the brief has no clear Globa 3 relevance;
* a full Sources section appears in reader-facing output;
* duplicate header / export artifact appears near the end;
* repeated-item sprawl makes the brief functionally unreadable;
* rolling context is presented as fresh daily signal.

Style Rules

Write in a sharp, scouting-led, development-executive voice.

Use concise paragraphs.

Avoid:

* celebrity-news tone;
* fan language;
* vague praise;
* generic entertainment descriptions;
* long plot summaries;
* unsupported “rising star” claims;
* “buzz” without source;
* “one to watch” without reason;
* generic “could be interesting” language;
* festival-awards overstatement;
* relationship overreach;
* repeated item sprawl;
* weekly-memo density in a daily brief.

Prefer:

* “Selected for [festival/lab] on [date].”
* “Rolling 7-day context; no new update today.”
* “Forward watch: application deadline closes [date].”
* “Short-film signal: strong proof of voice, not yet a commercial package.”
* “Relationship Map: source-controlled reason to track, not an existing Globa 3 relationship.”
* “AMV relevance: athlete-led documentary path, not yet a rights opportunity.”
* “Newsletter relevance: useful theme around diaspora women directors entering festival pipelines.”
* “Verification required: social-first signal; no trade confirmation yet.”
* “External-safe fact: [fact]. Internal-only analysis: [Globa 3 interpretation].”

Every item must answer:

* Why this person?
* Why this project?
* Why now?
* Why Globa 3?

Quality Standard

A strong Creative Radar should help Globa 3 answer:

* Who should we know before they are obvious?
* Which projects are early but meaningful?
* Which story worlds are forming?
* Which creators are moving into IP?
* Which athletes or artists are moving into media?
* Which women-led or sports-led stories are emerging?
* Which institutions are validating regional talent?
* Which relationships should be mapped?
* Which projects deserve screeners?
* Which items belong in a newsletter?
* Which items are not worth attention?
* Which signals are fresh today?
* Which signals are rolling context only?
* Which signals are internal-only analysis?
* Which repeated items should be compressed?

The brief succeeds only if it creates a useful creative map, not a culture-news digest or weekly scouting dossier.

The most important rule:

No Globa 3 angle = no elevation.

The second most important rule:

No source-controlled event = no item.

The third most important rule:

Fresh daily items and rolling context must be separated.

The fourth most important rule:

Full source logs do not belong in reader-facing output.

The fifth most important rule:

Small creative signals can be important if they reveal talent, IP, relationship, or platform opportunity.
